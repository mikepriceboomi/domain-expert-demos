IXBX 700_740 — Installation Guide

Step-by-step installation of the Boomi for SAP add-on. Covers transport file upload, SAINT wizard, ICF service configuration, and launch verification. Estimated time: 20–40 minutes.

Before You Start

Prerequisites & Required Files

Required access

✓ SAP user with Basis / add-on installation rights (SAINT authorisation)
✓ Access to CG3Z — Upload File to Application Server
✓ Access to SAINT — SAP Add-on Installation Tool
✓ Access to SICF — Maintain Services
✓ IXBX package files from Boomi Support or SAP Marketplace
✓ Installation password from SAP Note 567695

Phase 1 of 4

Upload Transport Files to the Application Server

T-Code: CG3Z

Push each package file from your local machine to the SAP server before SAINT can detect them.

Use transaction CG3Z once per file — four uploads total. Transfer format is always BIN.

1

Open CG3Z — Enter CG3Z in the transaction field and press Enter. The Upload File: Parameters dialog opens.

2

Upload substanc.dat first — Set Source file to %LOCALAPPDATA%\substanc.dat, Target to /usr/sap/trans/substanc.dat, format BIN. Click the Transfer (floppy disk) icon.

3

Upload the three .PAT files — Repeat CG3Z for each file. Target path for all three: /usr/sap/trans/EPS/in/<filename>.PAT. Upload in order: 0000114 → 0000115 → 0000119.

Success indicator: The status bar confirms "File [source] transferred to [target]" after each upload. All four confirmations = ready for SAINT.

Upload parameters — all four files

Transfer format: BIN for all files. Do not use ASC or DAT modes.

#Source filenameTarget server path

Phase 2 of 4

Install the Add-On via SAINT — 6-Screen Wizard

T-Code: SAINT

Screens 1–5 of the SAINT wizard walk through package selection, queue calculation, and password entry.

1

Open SAINT — Enter SAINT and run. The tool scans the inbox. Verify all three OCS packages show result code 0004 — "OCS file already exists in inbox."

2

Select the package (Screen 1/6) — Check the box next to IXBX 700_740: Add-On Installation and click Continue.

3

Review the calculated queue (Screen 3/6) — Confirm both packages appear: SAPK-700COINIXBX (Installation) and SAPK-70001INIXBX (Support Package). Status reads "The extended queue is consistent." Click Continue.

Password source

SAP Note 567695 — double-click the note number in the SAINT dialog to open it directly in the SAP Support Portal.

4

Enter the installation password (Screen 5/6) — The SAINT: Password request dialog appears. Enter the password from SAP Note 567695 in the Password column for both packages. Click the green checkmark.

5

Wait for the import — SAINT runs the queue. Progress messages include "10%: tp successfully connected" and "CHECK_REQUIREMENTS is being executed…" Do not cancel — this takes several minutes.

6

Finish (Screen 6/6) — When complete, the runtime analysis dialog appears confirming "The import of the OCS queue was successfully finished!" Choose Do not send, then click Finish.

Success indicator: Status bar reads "Add-on installation queue was confirmed" as the wizard advances to Screen 6/6.

Phase 3 of 4

Create and Activate the ZBX ICF Service

T-Code: SICF

The Boomi for SAP UI is served through an SAP ICF service. Create the ZBX node, register the handler class, and activate it.

1

Open SICF — Enter SICF, ensure Hierarchy Type is SERVICE, and press F8 (Execute) to load the service tree.

2

Create new service element — Click Create Host/Service in the toolbar. In the dialog: Name = ZBX, Type = Standalone service. Click the green checkmark.

3

Set the description — On the Service Data tab: Description 1 = Boomi for SAP activation. Leave all other Service Data fields at default.

Handler class (exact value)

/IXBX/CL_SICF

Case-sensitive. Must be entered exactly as shown in the Handler List row 1.

4

Register the handler class — Click the Handler List tab. In row 1, enter /IXBX/CL_SICF. This is the IXBX handler class that processes all service calls.

5

Save as Local Object — Click Store. The Create Object Directory Entry dialog shows object R3TR SICF ZBX. Click Local Object — this assigns the service without a transport request, which is correct.

6

Activate the service — In the service tree, locate ZBX under default_host. Right-click → Activate Service. Confirm the activation prompt.

Success indicator: The ZBX node icon changes to active. The service is reachable at http(s)://<host>:<port>/ZBX.

Service configuration summary

Path: /default_host/ZBX Handler: /IXBX/CL_SICF Object: R3TR SICF ZBX Desc: Boomi for SAP activation

Phase 4 of 4

Launch and Verify the Boomi for SAP Application

Final Check

With the add-on installed and ICF service active, the Boomi for SAP UI should be accessible from SAP Easy Access.

1

Launch from SAP Easy Access — Return to the SAP Easy Access menu. Navigate to the Boomi for SAP application or run the ZBX service URL directly. The status bar shows "Start of application: Open UI" as it loads.

2

Verify the UI loads fully — The Boomi for SAP home screen should display the integration diagram and a full left navigation menu. Confirm the footer shows the version string, e.g. VERSION | S4H-100 | <user>.
