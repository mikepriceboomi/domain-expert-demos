Phase 2 — Build the Nav Template

Wire the nav once · Duplicate for every page · Saves ~20 minutes

Every page shares the same top nav component. Rather than wiring 5 nav buttons on each of 5 pages, you build it once on Lab Home, then duplicate the page four times. Each duplicate already has the nav wired — you just update the active button and add the page content underneath.

Presentation Component 1 — Page Header (nav template) page-header
1
Go to the Lab Home page. Add a Presentation component. In Properties, set CSS Class to page-header.
2
Open TinyMCE source mode (</> button in the toolbar). Paste the HTML below, then click OK.
TinyMCE Source — paste this into the page-header Presentation
<nav class="header-nav"></nav> <div class="header-body"> <span class="eyebrow">Hands-on Lab &middot; Intermediate</span> <h1>Boomi for SAP</h1> <p>Connect SAP S/4HANA to Salesforce and databases using the Boomi for SAP connector. If something looks wrong
⚠
Columns stacking vertically instead of side by side The CSS class on the Inline Container is missing or misspelled. Double-check home-layout or exercise-layout is set on the container, not on one of the Presentations inside it.
⚠
Sidebar not sticking when you scroll The sticky behaviour comes from the exercise-sidebar class on the left Presentation. If the sidebar scrolls away with the page, check that class is set correctly.
⚠
TOC links don't scroll to the right place TinyMCE may have stripped the id attributes from the step section divs. Re-open TinyMCE source mode on the right Presentation and check that <div id="step1"> etc. are still there. If they were stripped, add <a name="step1"></a> just before each step section as an alternative.
⚠
Images not loading The images point to a public GitHub repo. If the repo has been made private, images will 404. Check the repo visibility at github.com/Boomi-Global-Field-Engineering/boomilabs.
